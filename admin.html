Koneksi Database Cloud (Supabase)

Hubungkan ke Supabase gratis agar perubahan langsung live otomatis ke semua HP & pengunjung

Cara Kerja Supabase: Saat kamu klik "Simpan", data langsung terkirim ke database Supabase milikmu. Landing page otomatis membaca data terbaru dari Supabase tanpa perlu kamu build atau deploy ulang!

Panduan 1 Menit Buat Tabel di Supabase (SQL Editor)

Copy kode SQL di bawah dan jalankan di menu SQL Editor di dashboard Supabase kamu:

CREATE TABLE IF NOT EXISTS site_content (
  id TEXT PRIMARY KEY DEFAULT 'h2c_main',
  data JSONB NOT NULL,
  updated_at TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc'::text, now())
);

ALTER TABLE site_content ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Public Read" ON site_content FOR SELECT USING (true);
CREATE POLICY "Public Insert/Update" ON site_content FOR ALL USING (true) WITH CHECK (true);
GRANT ALL ON site_content TO anon, authenticated;
